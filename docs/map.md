# Карта библиотек (2GIS MapGL)

Карта на главной странице с геометками библиотек Москвы. При клике на точку
показывается белая плашка с названием, режимом работы сегодня и телефоном.

## Из каких файлов состоит

| Файл | Что делает |
|---|---|
| `frontend/index.html` | Подключает скрипт 2GIS MapGL (`<script defer src="https://mapgl.2gis.com/api/js/v1">`) |
| `frontend/src/components/common/Map.tsx` | React-компонент: инициализация карты, маркеры, плашки |
| `frontend/src/components/common/libraries-list.json` | Данные библиотек (276 записей, выгрузка из open data Москвы) |
| `frontend/src/styles/components/common/Map.scss` | Стили секции карты и плашки |
| `frontend/src/styles/index.scss` | Подключает `Map.scss` (`@import './components/common/Map'`) |

Пакет `@2gis/mapgl` в проект **не устанавливается**: скрипт грузится из
`index.html`, а в `Map.tsx` описаны минимальные типы (`MapInstance`,
`MarkerInstance`, `HtmlMarkerInstance`) — этого достаточно для работы и не
тянет лишние зависимости.

## Как настраиваются ключевые параметры

Все константы — в начале `Map.tsx`:

```ts
/** Ключ API 2GIS (демо-ключ). */
const API_KEY = 'c2ce063b-1a5c-44d3-8bd2-4ba14bff9d3b';

/** Координаты Москвы (центр карты). */
const MOSCOW_CENTER: [number, number] = [37.6173, 55.7517];

/** Ожидание загрузки скрипта 2GIS: 100 попыток по 100 мс (~10 секунд). */
const POLL_INTERVAL_MS = 100;
const MAX_ATTEMPTS = 100;
```

| Параметр | Где менять | Значение по умолчанию |
|---|---|---|
| Ключ API | `API_KEY` | демо-ключ 2GIS; для продакшена — получить свой в [кабинете 2GIS](https://docs.2gis.com/ru/api/quickstart/dashboard) |
| Центр | `MOSCOW_CENTER` | Кремль: `[долгота, широта]` |
| Масштаб при открытии | `zoom` в вызове `new mapgl.Map(...)` | `12` — виден центр Москвы (не весь город) |
| Высота карты | `Map.scss`, `&__container` / `&__placeholder` | `555px` (по макету Figma, frame 1:821) |
| Скрипт 2GIS | `index.html` | версия `v1`, атрибут `defer` обязателен |
| Точки | `libraries-list.json` | 276 библиотек |

> **Порядок координат.** 2GIS использует `[долгота, широта]` (`[lng, lat]`),
> то есть сначала X, потом Y — в отличие от привычного «широта, долгота».
> В `libraries-list.json` координаты уже в таком порядке.

## Откуда берутся данные

Из `libraries-list.json`. Каждая запись содержит много полей, компоненту нужны
только четыре:

```jsonc
{
  "CommonName": "Библиотека №184",          // название для плашки
  "geodata_center": {                        // координаты центра [lng, lat]
    "type": "Point",
    "coordinates": [37.479713392, 55.633015181]
  },
  "WorkingHours": [                          // расписание по дням
    { "DayWeek": "понедельник", "WorkHours": "12:00-22:00" },
    { "DayWeek": "воскресенье", "WorkHours": "выходной" }
  ],
  "PublicPhone": [                           // берётся только первый
    { "PublicPhone": "(495) 339-86-77" }
  ]
}
```

Из JSON собирается массив `points: LibraryPoint[]` — уже без лишних полей:

- библиотеки **без координат** пропускаются (`getCoordinates` возвращает `null`);
- часы на сегодняшний день ищутся по `DayWeek`, совпадающему с текущим днём
  недели (`DAY_NAMES[new Date().getDay()]`);
- «открыта сегодня» = есть часы и в них нет слова «выходной» (`isOpenToday`).

## Как работает инициализация

Скрипт 2GIS подключён с `defer`, поэтому при первом рендере `window.mapgl`
ещё может не существовать. Компонент опрашивает его в `useEffect`:

```
tryInit()
  ├─ window.mapgl есть?  → создаём mapgl.Map и маркеры, выходим
  ├─ попыток < 100?      → ждём 100 мс и повторяем (всего ~10 секунд)
  └─ попыток ≥ 100       → setMapError(true) → «Карта временно недоступна»
```

При размонтировании компонента вызывается cleanup:

1. `destroyPlate?.()` — удаляет открытую плашку;
2. `destroyMarkers?.()` — удаляет все пины;
3. `map?.destroy()` — удаляет карту;
4. таймер опроса очищается, флаг `cancelled` не даёт «проснуться» устаревшему
   таймеру.

## Маркеры и плашка

### Пины (без подписей)

Для каждой точки создаётся обычный `mapgl.Marker` **без** `label` — на карте
только иконки, названия не показываются, чтобы 276 подписей не засоряли вид:

```ts
points.forEach((point) => {
  const pin = new MarkerCtor(createdMap, { coordinates: point.coordinates });
  pin.on('click', () => handlePinClick(point));
  pins.push(pin);
});
```

### Плашка по клику

По клику на пин создаётся `mapgl.HtmlMarker` — HTML-маркер, который умеет
принимает произвольную разметку (`html: HTMLElement | string`). Из него
собирается белая карточка (`createPlate`):

- **Название** — `CommonName`;
- **Статус** — «Открыто сегодня: 12:00-22:00» (зелёный) или
  «Закрыто сегодня: выходной» (красный); если записей за сегодня нет —
  «Сегодня: нет данных о режиме работы»;
- **Телефон** — первый из `PublicPhone`.

Плашка строится DOM-методами (`createElement`, `textContent`), а не
конкатенацией строк: данные из JSON так не попадают в разметку напрямую.

Логика переключения (в `tryInit`):

- `platedPoint` — точка, у которой плашка открыта (или `null`);
- клик по **тому же** пину → `hidePlate()`;
- клик по **другому** пину → `hidePlate()` + `showPlate(point)`;
- одновременно открыта максимум одна плашка.

Опции плашки:

```ts
{
  coordinates: point.coordinates,
  html: createPlate(point),
  zIndex: 1000,                  // поверх пинов
  preventMapInteractions: true,  // клики по плашке не уходят на карту
  interactive: true,             // плашка может быть целью pointer-событий
}
```

### Позиционирование и стили (`Map.scss`)

```scss
&__plate {
  position: absolute;
  left: 0;
  top: 0;
  transform: translate(-50%, calc(-100% - 34px)); // центр по точке, выше пина
  width: 260px;
  background: #fff;
  // + border, radius, box-shadow, &::after — стрелка вниз к пину
}
```

`HtmlMarker` ставит верхний левый угол корневого элемента в координаты точки,
поэтому `transform` центрирует плашку по точке и поднимает её над пином.

## Как добавить/изменить данные

- **Добавить библиотеки** — дописать объекты в `libraries-list.json`
  (обязательные поля: `CommonName`, `geodata_center.coordinates`;
  опционально — `WorkingHours`, `PublicPhone`);
- **другой город/центр** — поменять `MOSCOW_CENTER` и при необходимости `zoom`;
- **подпись под пином вместо плашки** — у маркера есть опция
  `label: { text, offset }`, но она умеет только текст, без HTML и статусов.

## Возможные проблемы

| Симптом | Причина |
|---|---|
| «Карта временно недоступна» | скрипт `mapgl.2gis.com` не загрузился (нет интернета, блокировка) или ошибка в конструкторе карты |
| Пустая карта, ошибок нет | неверный `API_KEY` — проверьте консоль браузера |
| Плашка не появляется | ошибка в консоли при клике; проверьте, что у точки есть `geodata_center` |
| Точки не отобразились | у записей нет координат — они пропускаются при сборке `points` |
| `npm run build` падает | окружение: проекту нужен Node ≥ 22 (rolldown), не связано с картой |

## Ручная проверка

1. Открыть главную — карта видна, центр Москвы, пины без названий.
2. Кликнуть пин — белая плашка: название, статус сегодняшнего дня, телефон.
3. Кликнуть соседний пин — плашка «переезжает».
4. Кликнуть тот же пин — плашка закрывается.
5. У библиотеки с выходным статус красный, у работающей — зелёный.
6. Покрутить карту/зум — плашка ездит вместе со своей точкой.
7. Уйти с главной и вернуться — карта пересоздаётся без ошибок в консоли
   (проверьте, что нет утечек: в консоли не должно расти число DOM-узлов).
